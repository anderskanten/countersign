# Decisions

One file per decision. Filename: `YYYY-MM-DD-short-slug.md`.

Format and procedure: `skills/decide/SKILL.md`.

Decisions that were abandoned or superseded stay here. A record of what
was tried and dropped is worth as much to a later participant as a record
of what held, and it is the only defence against relitigating the same
question every few weeks.

Empirical questions do not belong here. They belong in `reports/`, with a
run log.
